Token Unidasul (Azure Blob) UNIDASUL_SAS_TOKEN

Fonte de imagem real por EAN (blob <ean>_1.png). O token tem validade (parâmetro "se=" na URL que a Unidasul manda) — quando expirar, a busca nessa fonte simplesmente para de achar imagem (sem quebrar nada, cai pra próxima fonte); cole o token novo aqui pra reativar.

Token Serper (serper.dev) SERPER_API_KEY

Proxy pago da busca de imagens do Google de verdade (google.serper.dev/images) — alternativa quando a cota diária grátis do Google Custom Search (100 buscas/dia) esgota. Busca sempre com safe=active; mesmo assim toda imagem passa pela checagem de conteúdo (Gemini) antes de ser salva, igual às outras fontes.

Flags de Funcionamento

Usar OpenAI para Sugestões Quando ativo, as sugestões usam GPT-4. Quando desativado, usa busca fuzzy local.
Remoção de Fundo (rembg) Remove o fundo das imagens enviadas. Requer onnxruntime + VC++ runtime.
Busca de imagem online (Google/Zaffari/PreçoMelhor/Rissul/Sonda/Unidasul/Serper) Desativa a busca automática de foto crua em fontes externas — o terminal e o painel passam a usar só a imagem local já salva. Não afeta cadastro de nome/marca nem a aba "Buscar com IA". Use pra pausar tudo rapidamente em caso de imagem imprópria vindo de fonte externa.
Verificação imagem × descrição (OCR/IA) Antes de salvar qualquer imagem (busca automática, "Buscar com IA" ou upload manual), confere se ela plausivelmente é do produto cadastrado — só roda quando o produto já tem uma descrição pra comparar. Imagem que não parece corresponder vai pra quarentena (Configurações → Quarentena) em vez de virar a foto pública. Desative se estiver gerando falsos positivos demais (ex.: descrições muito abreviadas no catálogo).
⚠️ Gemini / Vertex AI (Google Cloud) — desliga tudo Chave mestra pra zerar o custo do Gemini. Desativado: arte publicitária, sugestão de nome/headline, o classificador de conteúdo impróprio E a verificação imagem×descrição acima (as duas rodam com Gemini) e o botão "Buscar com IA" ficam todos inertes, sem nenhuma chamada real à API — a chave configurada acima continua salva, só para de ser usada. Não afeta Google Custom Search nem Serper (fontes de busca de imagem separadas, sem custo de Gemini). Atenção: desligar isso também desliga a proteção contra imagem imprópria/errada (ver incidente documentado) — ligue de volta assim que o custo for resolvido.

Fontes de Imagem

Controle fino por fonte, complementar ao toggle geral acima. Ativa: liga/desliga essa fonte específica na cadeia de busca (as outras continuam funcionando normalmente). Revisão obrigatória: a fonte continua buscando, mas toda imagem que vier dela cai em quarentena pra revisão humana antes de virar a foto do produto — mesmo que o classificador de conteúdo aprove. Use pra exigir revisão manual de uma fonte específica sem precisar desligá-la (ex.: uma fonte que já trouxe imagem errada antes).

Cadastrar produto pelo EAN (busca no Cosmos)

"Buscar no Cosmos e cadastrar" consulta apenas o Cosmos (com rotação de tokens, se houver mais de um configurado) e ignora descrição/imagem preenchidas aqui — se não encontrar lá, nada é cadastrado; use a busca normal acima pra tentar outras fontes também. "Cadastrar manualmente" não consulta fonte nenhuma — cria o produto com o EAN e, se preenchidos, a descrição e a imagem acima; marca fica vazia até completar depois.
